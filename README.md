# AI Resume Health Check

Paste (or upload) your resume and a job description, pick a target role, and get a full health check — in English, Traditional Chinese, or Japanese.

**Live demo:** https://maokuanghsin.github.io/ai-resume-health-check/

## What it does

- **Overall match score (0–100)** — with a plain-language verdict and a five-part breakdown where every number explains itself
- **Skills check** — present / missing / extra skills, matched against a ~90-skill dictionary
- **Experience gaps** — years, degree, certifications, seniority, industry
- **Action verbs & quantified results** — does each bullet start with a strong verb and include a number?
- **Length & formatting checks**
- **Fix checklist ranked by impact** — High / Medium / Low priority
- **Before / after bullet rewrites** — with the reasoning and copy buttons
- **Honesty panel** — keyword matching is a guide, not a real ATS; never add skills you don't have

## Input options

- **Resume:** paste text, or upload a file (PDF, DOCX, TXT — parsed in the browser)
- **Job description:** paste text, upload a file (PDF, DOCX, TXT), or paste a job-posting URL to fetch it (if the site allows it; otherwise paste the text)

Target roles: AI Solution Architect, AI Engineer, Data Scientist, Data Analyst, Product Manager.

Two one-tap samples are included — a mid-strength AI Solution Architect pair and a deliberately weak Data Scientist pair — so you can see a strong and a weak report right away.

## Privacy

Runs **100% in the browser**. Your resume and job description are never uploaded or stored. The report can be copied in full or downloaded as a .txt file.

## How to use

Open the live demo above, or open `index.html` in any browser. No build step, no server.
